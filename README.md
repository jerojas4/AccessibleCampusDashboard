CampusDashboard
A Canvas-inspired student dashboard built using HTML, CSS, and JavaScript. This project focuses on creating a clean, responsive, and accessible student learning interface.

Features
- Interactive sidebar navigation
- Dashboard with upcoming assignments
- Courses section with search functionality
- Responsive course and assignment cards
- Smooth hover effects and animations
- Accessibility features including ARIA labels and keyboard navigation


Technologies Used
- HTML5 – Structure
- CSS3 – Styling and layout
- JavaScript – Interactive functionality


Accessibility
This project incorporates accessibility practices inspired by WCAG 2.2, including semantic HTML, accessible labels, and keyboard focus indicators.


Getting Started
1. Clone or download the repository.
2. Open index.html in your browser.
